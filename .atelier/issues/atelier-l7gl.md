## Goal

Stop every pull request from building all six release targets. `dist-workspace.toml` has `pr-run-mode = "upload"`, so each PR runs about three macOS release jobs alongside CI's macOS test job, and GitHub runs at most five macOS jobs at once. Switch to `pr-run-mode = "plan"` so PRs only run `dist plan`, and tag pushes still build and publish.

## Done when

`dist-workspace.toml` has `pr-run-mode = "plan"`; `.github/workflows/release.yml` is regenerated by `dist generate` at the pinned `cargo-dist-version` and has no hand edits (running `dist generate` again leaves it unchanged); the PR's Release run runs only the plan job; and S2's "Shown by" line in docs/strategies/release-distribution.md no longer expects PR runs to upload artifacts, with a dated change note.

## Context

Requested by Sumeet on 2026-11-04 as a follow-up to the release validation atelier-g6a1, which uses the PR upload runs as S2 evidence; do it after that validation. The strategy's Authority section lets the orchestrator change `dist` settings.
