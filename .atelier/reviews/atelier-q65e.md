Reviewed git diff master...HEAD (git_freshness, review_gate, evidence_freshness, epic_migration, migrate.rs, session test). Semantic equivalence: the cat-file batch runs under --no-replace-objects and resolves the same pinned expressions (including ^/~, grafts and shallow parents through get_oid). Missing, tag and non-commit objects map to the same errors. sha256 hash length comes from the oid length. Blobs are read by entry oid, so paths with newlines work. Submodule and directory entries still bail. Symlink and exec modes are kept. Non-UTF-8 paths fail as before. The tree diff lists both rename sides like git diff --name-status; copy and ignoreSubmodules config can only over-report. The ancestor-set path (rev-list) honors the same grafts and shallow boundaries as merge-base. Every cache key is a full oid, a pinned expression, or args built from full oids. Moving the FIX NOW ancestor check earlier and memoizing original_approval_valid per (approval id, finding target) keep the same conjunction of pure checks. Epic acceptance: the migrated text must equal the after record apart from status, updated_at, closed_at and Close Reason. Turning a record into an epic is caught by the issue_type front-matter check. claim_endpoint compares through the HEAD type, so a content edit is still a claim; the lossy-migration limit is filed as defer. cat-file errors drop and respawn the reader; Drop closes stdin and then waits, and I found no reachable deadlock. prefetch_histories uses scoped threads and leaves failures uncached, so history() reports them. The regression test fails on master code (205 vs 602 per-object calls; checked by applying only the test to a master export) and passes here. Results: cargo nextest run --workspace 617/617 pass; with --features test-hooks 621/621 pass; cargo fmt --check clean. git diff --check flags only trailing blank lines in generated evidence records, an existing pattern (29 of the first 50 evidence files on master end the same way). Release land on the main checkout (master 8e650903): 4.46 s and 4.10 s, exit 0, 687 git processes (30 cat-file). Debug land: 6.58 s. The Done when is met.
